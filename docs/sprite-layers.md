# 2D 立绘分层

主站使用 Canvas 2D，只加载 `public/sprites/layers/` 中的三张 WebP（共约 700 kB，由 PNG 原稿压缩而来）：

| 贴图 | 用途 |
|---|---|
| `character_base.webp` | 1024 × 1536 无五官底图：身体、服装、脸部皮肤、后发、猫耳、尾巴 |
| `face_atlas.webp` | 1254 × 1254 透明图集，3 列 × 4 行，共 12 个表情 |
| `hair_front.webp` | 1024 × 1536 原稿纹理；通过轮廓遮罩取出前景刘海，保留原始发丝形状 |

合成顺序为底图 → 五官 → 刘海。`src/sprite-art.js` 保存脸部位置、表情图集索引和刘海轮廓；不依赖图像生成工具精确保持裁切坐标。原稿纹理包含完整角色，但合成时只采样刘海区域，其他像素不参与绘制。

图集依次为微笑、眨眼、说话、开心、享受、睡眠、鼓腮、惊讶、委屈、撒娇、wink、害羞。五官采样遮罩排除生成图里多余的肤色和腮红边缘，肤色由底图提供。说话只切换嘴部，眨眼只切换眼部，避免整张脸跳动。图片须全部解码完成后一起显示；失败时显示重试入口，不展示未合成的脸。

最终表情按眼睛、眉毛、嘴分别组合，不直接整格替换。撒娇、害羞、说话和惊讶复用微笑眼型，避免眼距和瞳孔比例变化；享受、睡眠复用眨眼的闭眼形状；wink 只替换右侧眼睛。撒娇与害羞用小幅眉毛变化和腮红区分；说话嘴型缩至 58%，睡眠嘴型缩至 56%。

互动：

| 操作 / 状态 | 表情和动作 |
|---|---|
| 鼠标轻抚头部 / 挠下巴 / 底部互动按钮 | 享受、轻蹭、呼噜 |
| 戳脑袋 | 鼓腮、轻摇 |
| 碰脸颊 | 害羞、轻点 |
| 耳朵 / 尾巴 | 惊讶、轻弹 |
| 铃铛 / 身体 | 开心、轻点 |
| 打招呼 / 切换方言 | 开心、轻晃 |
| `nya` / `miao` / `meow` | wink |
| `1xc` | 开心、弹跳、爱心 |
| 寂寞第 1–2 / 3–4 / 5 段 | 撒娇 / 委屈 / 睡眠 |

呼吸、刘海摆动和互动动作都由代码驱动；减少动态效果偏好会禁用位移和粒子。当前没有独立手臂骨骼或挥手姿势。

运行 `npm run dev` 后访问 `/sprite-preview.html`，可对照原图检查全部表情。这是开发校准页，默认 Vite 生产构建只包含主站。精确生成提示词保存在 `sprite-generation.json`；`sprite-prompts.md` 保留原始美术需求。
